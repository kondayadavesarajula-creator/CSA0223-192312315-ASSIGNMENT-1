## 1. Assignment Overview

This assignment focuses on the design, implementation, testing, and analysis of an Electricity Billing System using the C programming language.

The assignment covers fundamental and advanced C programming concepts, including data types, constants, macros, header files, conditional compilation, input validation, type conversions, preprocessing, compilation, linking, memory management, and smart-meter-based billing.

A total of **12 tasks** are organised into separate folders. Each task contains its respective source code, required files, and output screenshots.
